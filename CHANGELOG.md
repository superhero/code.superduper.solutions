# Changelog

## Staging

- Add explicitly installed browser-local Bonsai 2 and Ornith 1.5 profiles with pinned WebML/Wllama runtimes, verified chunked storage, compatibility checks, images, and the existing Pi tools and skills.

- Add optional GitHub, GitLab and Bitbucket SDK connections, encrypted browser credentials, full-history HTTPS cloning, reviewed remote Git synchronization, and hosted requests, issues and checks with fixture-only upstream validation.

- Establish the reusable browser editor foundation: Svelte UI and local development tooling, diagnostics, test/report infrastructure, repository policies, and prepared release automation.

- Add the browser-local repository editor, configurable CodeMirror interface, directory import, persistent Git-backed undo/redo and independent explicit source commits.

- Add an original function-mark favicon with inline SVG, generated ICO/PNG and Apple touch fallbacks, additional compatibility formats, and build-time freshness checks.
